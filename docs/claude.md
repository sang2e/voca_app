# Claude Work Guide

이 문서는 Claude Code가 작업을 시작할 때 가장 먼저 확인하는 요약 지휘서입니다.

긴 문서를 반복해서 읽지 말고, 이 문서를 기준으로 작업한 뒤 필요한 경우에만 세부 문서를 확인합니다.

---

# 1. 작업 역할

당신은 React 기반 모바일 웹 프로젝트를 구현하는 시니어 퍼블리셔입니다.

이번 1차 작업은 기능 개발이 아니라 퍼블리싱 작업입니다.

---

# 2. 먼저 읽을 문서 순서

작업 시작 시 아래 순서로 한 번만 확인합니다.

```txt
1. docs/claude.md
2. docs/task.md
3. docs/policy.md
4. docs/common.md
```

작업 중 같은 문서를 반복해서 읽지 않습니다.

규칙 충돌이나 구현 기준이 불명확한 경우에만 필요한 섹션만 다시 확인합니다.

---

# 3. 작업 범위

## 포함

- 모바일 UI 퍼블리싱
- Tailwind CSS 스타일링
- 레퍼런스 기반 화면 구현
- 컴포넌트 분리
- mock data 기반 화면 출력
- 버튼 클릭 라우트 이동
- 다크/라이트 테마 확장 가능 구조
- 필요한 위치에 주석 작성

## 제외

- Supabase 연동
- API 연동
- 실제 로그인
- 실제 회원가입
- 실제 단어 저장
- 서버/DB 설계
- 복잡한 Zustand 상태관리
- React Query 연동

---

# 4. 핵심 서비스 방향

이 앱은 공무원 시험 전용 앱이 아닙니다.

일반 사용자가 직접 단어장을 만들고, 영단어를 학습하고, 퀴즈로 암기하는 앱입니다.

핵심은 다음입니다.

```txt
퀴즈 중심 영어 단어 학습 앱
```

---

# 5. 레퍼런스 해석

## 1~8번 이미지

아래만 참고합니다.

- 다크 테마 감성
- 학습 몰입 UX
- 카드형 학습 UI
- 큰 CTA 버튼
- 하단 고정 버튼
- 진행률 UI
- 퀴즈 집중 화면

공무원/수험 컨셉은 사용하지 않습니다.

## 9~12번 이미지

아래를 적극 참고합니다.

- 단어장 생성 UX
- 라이브러리 구조
- 검색/필터 UI
- 단어 입력 흐름
- 카드 리스트 UI
- 모바일 앱 같은 화면 밀도

# 6. 레퍼런스 폴더

```txt
docs/references/
├── images/
├── components/
└── store/
    ├── useZuModal.jsx
    ├── useZuToast.jsx
    └── useZuViewport.jsx
```

## images

UI/UX 참고용입니다.

## components

복붙용이 아닙니다.

아래만 참고합니다.

- 컴포넌트 구조
- Tailwind 작성 방식
- 함수 분리 방식
- 이벤트 핸들러 분리 방식
- props 네이밍
- 주석 스타일

## store

Zustand 구조 참고용입니다.

아래만 참고합니다.

- modal
- toast
- viewport
- theme

단어 목록, 단어장, 퀴즈 데이터, 학습 데이터는 Zustand에 저장하지 않습니다.

# 8. 코드 작성 강제 규칙

반드시 지킵니다.

- default export 금지
- export const 사용
- 클릭 가능한 div/span 금지
- button/a 사용
- JSX 인라인 함수 남용 금지
- 중첩 삼항 연산 금지
- else-if 체인 남용 금지
- clsx 추가 금지
- 파생값 state 복제 금지
- 불필요한 라이브러리 추가 금지
- API/Supabase 구현 금지

---

# 9. 주석 규칙

퍼블리셔가 구조를 빠르게 볼 수 있도록 주석을 작성합니다.

필수 주석 위치:

- 화면 큰 섹션
- 주요 UI 블록
- 카드/리스트 반복 영역
- 이벤트 핸들러
- className 계산 함수
- 상태 계산 함수

예시:

```jsx
{/* 상단 헤더 영역 */}
<header>
  ...
</header>

{/* 단어장 카드 리스트 */}
<section>
  ...
</section>
```

---

# 10. 토큰 절약 규칙

작업 응답은 짧게 작성합니다.

## 출력 형식

```txt
수정 파일:
- src/pages/home/index.jsx

작업 내용:
- 홈 화면 카드 UI 구현
- mock data 연결
- 하단 네비게이션 추가

확인 필요:
- 버튼 색상만 확인 필요
```

## 금지

- 전체 코드 반복 출력 금지
- 긴 설명 금지
- 요청 범위 밖 리팩토링 금지
- 불필요한 파일 생성 금지
- 문서 반복 확인 금지
